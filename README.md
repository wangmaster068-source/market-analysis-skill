# 市场分析方法库 Skill

个人制作的管理/市场分析 Agent Skill：**7 大类、100 个分析工具与方法**，每个方法包含定位、用法、案例出处、落地缺陷、标签和功能分类。

它不是“万能模板”，而是一份**选方法、查缺陷、按链路推进**的速查库，适合战略分析、市场/竞品分析、营销规划、绩效与质量改善、投资决策、项目排期等场景。

## 目录结构

```text
market-analysis-skill/
├── SKILL.md
└── references/
    ├── 01-方法详述与缺陷.md      # 全文：每个方法怎么用 + 翻车点
    ├── 02-方法速查与适用范围.md  # 按功能分类的速查表
    └── 03-方法关系网.md          # 方法之间的关系与推荐链路
```

## 安装

### DSH（DeepSeek Harness）

把整个目录放到用户级 skills 目录：

```powershell
# Windows
Copy-Item -Recurse . "$env:USERPROFILE\.dsh\skills\analysis-methods"
```

```bash
# macOS / Linux
cp -R . ~/.dsh/skills/analysis-methods
```

重启会话后，Agent 会在需要选分析框架时自动加载；也可以直接说“用分析方法的 skill 帮我看这个方案”。

### 其他支持 Agent Skills 的工具

将 `SKILL.md` 与 `references/` 放入对应工具的 skills 目录即可；`SKILL.md` 的 frontmatter 已包含 `name` 与 `description`。

## 使用方式

1. **先定问题类型，再选方法**：定位 / 诊断 / 决策 / 执行 / 度量。
2. **检查结构重复**：BCG≈GE≈DPM≈IE、综摄法≈戈登法、定置管理≈5S 的整顿，只选一个。
3. **按链路走**：例如营销先 STP 再 4P，项目先 WBS 再甘特。
4. **输出结论时带上该方法已知缺陷**，不要把工具当真理。

## 设计原则

- 例子只用可核实的出处；没有公开案例就写“仅方法层说明”，不编企业案例。
- 缺陷写具体翻车机制，不写“需要高层支持”这类空话。
- 同一份分析里不出现结构重复的两个矩阵。
